This project analyzed a retail sales dataset using Microsoft Excel to uncover business insights.
I cleaned and organized the data, then used PivotTables, charts, and conditional formatting to answer five key questions about sales, profit, trends, unprofitable sub-categories, and top customers.
An interactive dashboard was created to visualize findings clearly and allow dynamic filtering by region, category, and time. 
Key insights include identifying the most profitable products, regions, and customers, as well as unprofitable segments despite high sales.
The project strengthened my data analysis, visualization, and problem-solving skills using Excel.
